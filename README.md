# algo-prog-course
ПР1. Ответы на контрольные вопросы
1. В Python из за того, что там читается код построчно и тут же выполняет, ошибка выдается только тогда, когда доходит очередь до самой строки, где есть ошибка. В C# код сразу полностью проверяется и, если будет хоть 1 ошибка, компилятор откажется работать.
2. Собирает проект, затем запускает программу.
3. В bin/ кладется результат сборки, в obj/ служебные промежуточные файлы, и тк оба не являются исходным кодом, их не обязательно хранить в Git.
4. git commit - сохраняет измененный проект и прикрепляет к нему сообщение. git push - это то, что отправляет проект в GitHub.
5. + - соединяет только между собой строки и переменные. $"..." - соединяет все строки и измененные
значения переменных в {}. Я использую 2 способ, тк это более экономный вариант, который не будет занимать большое место в коде. 
6. Если мы поделим int на int, получится целочисленный, неокругленный ответ. Для дробного ответа надо чтобы делимое/делитель были типа double.
7. Const не дает поменять случайным образом переменную, в который он был добавлен. Пример: в некоторых формулах физики есть постоянные величины, которые ни в каких случаях не меняются, к ним как раз можно будет применить const.
8. top-level statements - компилятор, который самостоятельно проверяет код и делает его немашинно-независимым. class Program{ static void Main() } и top-level statements отличаются тем, что 2-й самостоятельно может проверить и перевести код, в то время как с class Program{ static void Main() } надо делать проверку и перевод вручную.
